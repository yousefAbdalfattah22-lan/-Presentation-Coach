# 📖 Project Overview

Presentation Coach is an AI-powered application that helps university students improve their presentation skills. It generates realistic audience questions based on a presentation topic and evaluates students' answers, providing scores, strengths, weaknesses, and suggestions for improvement.
---

# ✨ Features

* AI-generated audience questions based on the presentation topic.
* AI-powered evaluation of student answers with scores out of 10.
* Personalized feedback highlighting strengths, weaknesses, missing information, and improvement tips.
* Interactive and professional Streamlit user interface.
* Session statistics, including questions answered and average score.

# ⚙️ Installation

### Prerequisites

* Python 3.10 or later
* A Kaggle account with GPU access
* An ngrok account and authentication token
* Visual Studio Code

### Setup

1. Clone or download the project.
2. Install the required Python packages:

```bash
pip install streamlit requests
```

3. Open the Kaggle notebook and run the cells to load the Mistral Nemo model and start the FastAPI server.
4. Copy the public ngrok URL generated by the notebook.
5. Configure the `BASE_URL` in `app.py` using the generated URL.
6. Make sure the API key in the frontend matches the backend API key.
7. Run the application:

```bash
streamlit run app.py
```

---

# 🚀 Usage

1. Launch the application using Streamlit.
2. Enter your presentation topic, such as Artificial Intelligence.
3. Click **Generate Audience Question** to receive a question from the AI.
4. Write your answer in the answer box.
5. Click **Evaluate My Answer** to receive a score out of 10 and detailed feedback.
6. Review your strengths, weaknesses, missing information, and advice.
7. Generate new questions to continue practicing and monitor your session statistics.

**Note:** The Kaggle notebook and ngrok connection must remain active while using the application.
